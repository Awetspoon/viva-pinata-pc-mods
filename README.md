# Viva Piñata PC Mods

Thirteen mods for the original two-disc **Windows PC release** of Viva Piñata. Install your own copy of the PC game first. The installer checks for the supported retail executable.

## Install

1. Download the mods ZIP from [Releases](https://github.com/Awetspoon/viva-pinata-pc-mods/releases) and extract it.
2. Copy your installed game folder and name the copy **Viva Pinata - Garden Lab**.
3. Follow **README.txt** to add XLiveLessNess 1.6.2.1, run **Install Mods.exe** and set the first-launch display mode. The installer reads the portraits, seed artwork and lantern template from your PC installation.
4. Open **Viva Pinata.exe** from the copied folder and start a new garden.

**Controls.txt** explains the Ally and Xbox controls. **What Each Module Does.txt** lists all thirteen modules.
